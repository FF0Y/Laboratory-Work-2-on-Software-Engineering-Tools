# Описание проекта

Проект на Python считает **площадь и периметр** круга и квадрата.

- `circle.py` — функции для круга.
- `square.py` — функции для квадрата.

## Функции и примеры

`r` — радиус круга, `a` — сторона квадрата. Мы используем числа не меньше нуля.

Примеры выполнения в Python.

### circle.area

Возвращает площадь круга:

```python
print(circle.area(2))  # 12.566370614359172
```

### circle.perimeter

Возвращает длину окружности:

```python
print(circle.perimeter(3))  # 18.84955592153876
```

### square.area

Возвращает площадь квадрата:

```python
print(square.area(4))  # 16
```

### square.perimeter

Возвращает периметр квадрата:

```python
print(square.perimeter(4))  # 16
```
